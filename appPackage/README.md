# Microsoft Teams app package

This folder contains the Microsoft Teams app manifest for installing the read-only Growth Command Centre demo as a Teams personal tab.

## Package before upload

Create a zip containing these files at the root of the zip:

- `manifest.json`
- `color.png`
- `outline.png`

The icon files are generated placeholders. Replace them with David James branded PNG icons before wider sharing.

## Install in Teams

1. Open Microsoft Teams.
2. Go to **Apps > Manage your apps > Upload an app**.
3. Upload the zipped app package.
4. Open **Growth Centre** from Teams.

The current tab URL is:

`https://unleashed2025.github.io/david-james-growth-command-centre/read-only/`
